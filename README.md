# Мировое господство

Онлайн-стратегия для 2–4 игроков: захватывай башни на нарисованной карте мира, расти армию и завоюй мир.

Установка пакетов не нужна: сервер написан на чистом Node.js.

## Как запустить в GitHub Codespaces

1. На github.com создай репозиторий и открой в нём Codespace (**Code → Codespaces → Create codespace on main**).
2. Загрузи файлы: правой кнопкой по пустому месту в левой панели → **Upload...** → выбери `world-domination.zip`. В терминале:
   ```bash
   unzip -o world-domination.zip && rm world-domination.zip
   npm start
   ```
3. Внизу открой вкладку **Ports**. У порта **3000** нажми правой кнопкой → **Port Visibility → Public**. Без этого друзья не смогут зайти.
4. Открой адрес порта 3000, введи имя, нажми «Создать комнату».
5. Кнопка «Скопировать ссылку для друзей» даёт ссылку вида `https://....github.dev/?room=ABCD`. Друзья открывают её, вводят имя и нажимают «Войти».
6. Хост выбирает скорость и нажимает «Начать игру».

Public можно включить и командой: `gh codespace ports visibility 3000:public -c $CODESPACE_NAME`

Сохранить игру в репозитории: `git add . && git commit -m "Игра" && git push`

Codespace засыпает после ~30 минут без активности, а бесплатных часов в месяц ограниченное количество. Держи вкладку Codespace открытой, пока играете.

## Правила

- Каждая башня сама растит бойцов: **+1 в секунду**. Больше 50 бойцов в одной башне не вырастает.
- Клик по своей башне — над ней появляется кнопка «Улучшить»: за золото башня начинает давать **+2 бойца в секунду**, потом +3 и так далее до +6. Цены: 30, 60, 120, 240, 480.
- Золото капает с каждой башни по 2 в секунду. Чем больше башен, тем больше золота.
- Атака: **потяни от своей башни к соседней** (стрелкой) и отпусти. Идут сразу все бойцы, кроме одного, и на карте они видны россыпью точек: сколько бойцов, столько точек.
- Если пришло больше бойцов, чем стоит в башне, она твоя (и её улучшения сбрасываются). Если меньше или поровну, защитники теряют столько же бойцов.
- Можно ходить и по морю: там пунктирные линии.
- Победа: захватить все башни или остаться последним игроком.

## Файлы

| Файл | Что внутри |
|---|---|
| `server.js` | сервер: комнаты, золото, рост бойцов, бои, победа. Баланс (цены, скорость роста, потолок) — константы в начале файла |
| `map.js` | карта мира: многоугольники материков, центры территорий, морские пути |
| `index.html` | весь клиент: меню, лобби, рисованная карта на canvas |
| `.devcontainer/` | настройки Codespaces: Node 22, порт 3000, автозапуск |
